# AI Job Assistant v1 Notes

## What this project does

This project checks a job description and compares it against a list of common AI/software skills.

## Why I built it

Freshers often struggle to understand what skills a job description is asking for. This tool helps make skill gaps visible.

## What I learned

- How to create a simple Python project
- How to use lists in Python
- How to check if text contains certain keywords
- How to organize a beginner portfolio project
- How to prepare a project for GitHub
